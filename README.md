# 黑暗森林 · Cloudflare 在线房间版

2026-10-24：主菜单包含开始游戏、游戏设置；用户名保存在本浏览器，原有同设备 Demo 位于设置页。在线房间由 Cloudflare Workers 与 SQLite Durable Objects 提供服务，WebSocket 按玩家发送各自视角，刷新可恢复原座位。

- 创建或从列表加入房间；房主可添加简单“汪淼”、普通“章北海”、困难“智子”或 DeepSeek，前三种重复角色有编号。真人加 AI 满 3 人可开局，最多 6 人；在线使用标准初始局面。
- AI 在服务器运行，前三种使用本地策略；每个 DeepSeek 座位在 Durable Object 中保存独立的整局对话，开局写入星图、航线、卡牌与规则，之后逐次追加该 AI 可见的局面变化，只在需要它决策时调用 `deepseek-flash`。由于 DeepSeek API 无状态，决策时会重放本局消息；对局越长，单次输入与费用越高。模型只接收自身私牌/坐标及公开信息，不读取其他玩家隐藏状态；调用失败时退回“智子”策略。所有 AI 每次出牌前固定等待 5 秒。
- 在线牌桌在自己的行动回合开始时显示提示；本方星系有在飞打击时持续显示红色警告。游戏中可主动退出，离开的座位由简单 AI 接手；所有真人退出后房间关闭。
- 进入牌桌有象征性入场与分区显现动画；宽屏按实际视口协调星图、手牌和玩家席位大小。地图下方并列显示本次与上一动作，加入房间不显示绿色成功弹窗。
- 服务端校验房主权限、行动座位、费用和规则；请求去重及版本检查防止重复结算。广播使用独立批次标识，允许同批回应并发，旧批次动作不能进入下一批。
- 在线洗牌与坐标随机化使用安全随机数。网络响应不包含牌库顺序、其他人的手牌/坐标、未揭示广播牌面或其他玩家的打击总航程。账号登录系统、跨浏览器座位找回、真人行动超时尚未实现；昵称不是账号。

本地完整服务：安装依赖后运行 `pnpm dev`，或 `node node_modules/wrangler/bin/wrangler.js dev --ip 0.0.0.0 --port 8787`。访问 `http://127.0.0.1:8787/`。原 `node serve.mjs` 仅提供静态 Demo，不能处理在线房间。

测试：`node --test test/*.test.mjs`；本地联机端到端测试：`node scripts/check-worker.mjs`（需先启动 Wrangler）。规则、联机、可见性与 DeepSeek API 请求边界由 Node 测试覆盖；AI 整局模拟仅覆盖三档本地策略。浏览器检查包含主菜单、昵称保存、房间创建、AI 玩家、广播发布/回应/揭示、真实鼠标拖动及刷新恢复。手机横竖屏是视口模拟，实体 Edge 触摸与性能仍需真机验证。

部署：`pnpm deploy` 或 `node node_modules/wrangler/bin/wrangler.js deploy`。配置为 `wrangler.jsonc`，Worker 入口 `server/worker.js`。首次部署自动建立 `GameRoom` 与 `RoomDirectory` 两个 SQLite Durable Object 类。不要把本机 `.wrangler`、OAuth 配置、日志或 `.env` 提交或上传。

DeepSeek 云端 AI 需要在 Worker 配置 Secret：`npx wrangler secret put DEEPSEEK_API_KEY`。本地 `wrangler dev` 可在 `web-preview/.dev.vars` 中设置 `DEEPSEEK_API_KEY=...`（此文件已被 Git 忽略）。没有配置密钥时，服务器会阻止房间添加该 AI，并提示管理员配置。

用户已授权部署到自己的 Cloudflare 账户；Sites 仍保持暂停同步。最新发布地址与版本记录于 `../docs/Cloudflare部署记录.json`。

## 本地运行

在此目录运行 `node serve.mjs`，打开终端显示的地址。默认端口 4173，可通过 `PORT` 环境变量更改。规则与展示测试运行 `node --test test/*.test.mjs`。

## 预览边界

这是浏览器内存中的本地接力试玩，不是联网对战。没有 AI、账号、存档、多人服务器或断线重连；刷新页面会重置演示。完整状态在本机，不能对拥有本机调试权限的人保密，不能用于远程公平对战。

初始打开的是第 3 轮演示局面，预置 12 点能量及建筑以便直接体验。点击“新对局”可选标准开局：每人 3 点初始能量、4 张牌，首位玩家已收到固定基础产能。

广播目前由同一设备的玩家手动接力表态，未接入联网版的广播等待、自动超时与重连。飞船抉择已有 30 秒放弃超时。没有采用尚未确认的 240 回合热寂兜底。

未裁定的边界暂采用以下预览口径，不能视为用户新增规则：空星系打击落空且不改变环境；同批到期打击顺序处理，遇到飞船抉择暂停；出局座位也计入内部计时索引；零存活时自动推进剩余打击；出局发起者的奖励仅记能量，不恢复生存。

可见数据过滤的联机契约尚未实现。正式联网版须将规则状态放在权威服务端并逐玩家过滤，不能把本地完整状态直接广播给客户端。
